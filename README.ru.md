# Horizon Drift

[English](README.md) · **Русский**

**Horizon Drift** - аркадные гонки и дрифт в 3D на одной HTML-странице. Работает в браузере без
сервера и без интернета: откройте `index.html` или играйте онлайн.

**[▶ Играть онлайн](https://alexalesha.github.io/HorizonDrift/)**

> Фанатская игра. Не связана с Microsoft и Playground Games и не одобрена ими. Все машины,
> трассы, гонщики и названия выдуманы. Модели, текстуры, звук и музыка сделаны кодом прямо в игре.

## Что есть в игре

- **Карьера:** 5 кубков по 3-4 события; медали открывают следующий кубок, призовые - на машины и
  тюнинг в «Гараже» (двигатель, шины, подвеска, облегчение, нитро, краска и диски).
- **Режимы:** гонка, дрифт (очки за угол и длинные серии, множитель до ×5), на время, дуэль с
  чемпионом кубка, на вылет.
- **8 машин и 8 трасс** по асфальту, гравию, снегу, траве и песку; покрытие меняет сцепление.
- **Свободная езда по 4 большим картам** (Побережье, Горы, Пустыня, Мегаполис), которые
  подгружаются вокруг машины: дороги с мостами и тоннелями, фестиваль, события на карте, быстрое
  перемещение, день и ночь, погода, карта (M) и фоторежим (F).
- Камеры: сзади, дальняя, с капота и салон с приборной панелью.
- Физика с кругом трения, антипробуксовка, ABS и помощь рулём (всё отключается); соперники с
  ИИ; синтезированный звук мотора и музыка; рекорды и настройки сохраняются.

## Управление

| Клавиша | Действие |
|---|---|
| W / ↑ | газ |
| S / ↓ | тормоз и задний ход |
| A D / ← → | руль |
| Пробел | ручник: сорвать заднюю ось в занос |
| Shift | нитро (копится в заносе) |
| E / Q | передача вверх / вниз (ручная коробка) |
| C | камера |
| V | взгляд назад |
| R | вернуться на трассу |
| P или Esc | пауза |
| M / F / E | карта / фоторежим / действие (свободная езда) |

Клавиши меняются в «Настройках». Геймпад: стик - руль, курки - газ и тормоз.

## Запуск у себя

Откройте `index.html` в Chrome, Edge или Firefox. three.js r149 лежит в `vendor/` (MIT, см.
`vendor/three.LICENSE.txt`), ничего не скачивается.

## Проверки

Законы игры - проверки Playwright в `tests/`: физика, карьера, открытый мир (связность дорог,
подгрузка на 300 км/ч, память за 10 минут езды), твёрдость мира, камера. Они открывают страницу
по файловому адресу в безголовом Chromium, по одной за раз:

```
npm install
npx playwright install chromium
npm test
```

Захват мыши в проверках всегда поддельный: настоящий `requestPointerLock` в безголовом Chromium
на Windows может зажать курсор пользователя. `npm run screenshots` делает кадры выше.
